
## 1. Teacher And Admin Accounts

The sign-in screen has demo Admin and Teacher accounts. These accounts are only for demonstrating role-based screens and must not be used as real school security.

## 2. Role-Based Access

The Management area displays the signed-in role. Admin-only controls are used for class setup while teachers can work with attendance sessions and schedules.

## 3. Class And Section Setup

Class and section entries are saved locally and can be used when creating attendance sessions and schedules.

## 4. Attendance Sessions

Create a dated session and select it as the active session. Scans are separated by session so the same student can attend more than one session in a day.

## 5. Class Schedules

Save the class day, start time, and end time. The schedule list is stored in the browser.
